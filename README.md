 📊 AI Sentiment Analysis Dashboard

 🚀 Overview
This project is an AI-powered sentiment analysis web application built using Python and Streamlit. It analyzes customer reviews and classifies them as Positive, Negative, or Neutral.

---

 ✨ Features
- 🧠 Sentiment analysis using NLP (TextBlob)
- 📊 Interactive dashboard with charts
- 📁 Upload CSV file for bulk analysis
- 💾 Download processed results
- 📈 Real-time statistics (Positive, Negative, Neutral)

---

 🛠 Tech Stack
- Python
- Streamlit
- Pandas
- TextBlob
